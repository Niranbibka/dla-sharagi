# промпт.

Минималистичный русскоязычный журнал о промптинге и вайбкодинге. React 19, TypeScript, Vite, Lucide.

## Запуск

```sh
pnpm install
pnpm dev
```

Сборка: `pnpm build`. Просмотр сборки: `pnpm preview`.

Статьи находятся в `src/data/articles.ts`. Работают фильтры, поиск, отдельные страницы статей, копирование примеров и закладки. Закладки сохраняются в localStorage.

Дизайн: карточки и компактная панель фильтров, шрифт Inter Tight. Чёрная тема использует фон #000000 и нейтральные серые поверхности; светлая — #fafafa. Без цветных градиентов, свечений и цветных теней.

Анимации на Motion: короткое появление карточек, плавная перестройка сетки и индикатор фильтра, небольшой отклик на нажатие. Без параллакса, наклонов, пульсации и пружин. Между статьёй и каталогом — короткое затухание без растягивания текста и обложки. Возврат сохраняет позицию, фильтры и поиск. Повторная навигация отменяет предыдущий переход. Для reduced motion движения отключены.

Материалы построены по [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/materials): оптический слой у плавающей панели и навигации, спокойная поверхность у читаемого контента. `GlassSurface` создаёт карту нормалей суперэллиптической кромки и применяет SVG `feDisplacementMap` к заднему плану; текст остаётся отдельным передним слоем. Карта пересчитывается при изменении размеров. Если URL-фильтры недоступны, остаётся обычное размытие.

Углы используют `corner-shape: superellipse(2)` по [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/corner-shape). Кромки и область нажатия наследуют геометрию; при отсутствии поддержки применяется обычное скругление. Темы переключаются кнопкой в панели, выбор сохраняется в localStorage. В чёрной теме на фоне редкие статичные белые звёзды.
